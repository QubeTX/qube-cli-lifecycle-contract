# Presentation snapshots

Terminal snapshots are parameterized with `{{UPPER_SNAKE_CASE}}` variables. Products substitute
values but preserve line order, labels, punctuation, and result language. ANSI styling is applied
only to existing tokens and is absent from these canonical no-color snapshots. The `ascii-*`
snapshot defines automatic fallback substitutions for terminals that cannot safely render Unicode.

JSON snapshots are complete schema-valid examples, not templates.
